# 📇 Contact Management System

A simple **Contact Management System** built using **C++** and the **Singly Linked List** data structure.

This project is part of my **DSA Learning Journey**, where I build small projects to practice and understand Data Structures and Algorithms through real implementations.

---

## 📌 Features

* ➕ Add a new contact
* 📋 Display all contacts
* 🔍 Search for a contact by name
* 🗑️ Delete a contact
* 🧭 Interactive menu-based program

---

## 🧠 Data Structure Used

This project implements a **Singly Linked List**.

Each contact is stored inside a `Node` containing:

* Contact name
* Phone number
* Pointer to the next contact

Example:

```text
HEAD
 ↓
[Contact 1] → [Contact 2] → [Contact 3] → nullptr
```

The program uses several important Linked List concepts:

* `Node`
* Pointer
* `head`
* `next`
* Dynamic memory allocation using `new`
* Memory deallocation using `delete`
* Traversal
* Searching
* Node deletion
