# 🌐 Browser History System

A simple Browser History System built using C++ as part of my Data Structures & Algorithms learning journey.

## 📌 About

This project is designed to simulate a browser history system using the Stack data structure.

## 🧠 Data Structure Concept

This project focuses on the Stack data structure, which follows the LIFO principle:

**Last In, First Out (LIFO)**

The most recently visited page is the first one accessed when navigating back through the history.
