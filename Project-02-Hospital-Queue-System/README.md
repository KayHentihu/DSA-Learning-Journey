# 🏥 Hospital Queue System

A simple Hospital Queue System built using C++ as part of my Data Structures & Algorithms learning journey.

## 📌 About

This project is designed to simulate a hospital queue system and practice the fundamental concept of a Queue data structure.

## 🧠 Data Structure Concept

This project focuses on the Queue data structure, which follows the FIFO principle:

**First In, First Out (FIFO)**

The first patient added to the queue will be the first patient to be served.
